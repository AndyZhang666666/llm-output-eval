# 证据复核工作台精修

开发基线：`af60f5b`。本轮不修改模型评分、量表、均分、导入格式、URL、业务存储键或报告字段。

## 设计取舍

- 对象是带着一份创意文本和已有评价来复核的作者。主要任务是核查一条评语，留下独立判断，而非浏览仪表盘。
- 视觉借用校样纸：页眉展示当前材料，左侧五维像页边索引，原文与评语成为对页。纸白、铅字、校样红、原文高亮的浅赭色只承担层级与状态。
- 材料管理集中到一处；选择来源与复核判断不再同时占满首屏。现有导入、资料库和外部任务处理函数保持。
- 原文与判断在桌面并置；手机定位引用后提供明确返回，不重建当前维度或人工编辑。
- 相邻量表档供核对，全量规则展开；原分、人工参考和适用性继续独立。
- 一篇材料只保留一个处理清单编辑区；换维度时未提交任务草稿留在原标签页草稿层。
- 导出格式归入一个菜单；清除或撤回人工层经过明确确认。清除不删除模型原始记录和独立处理项。
