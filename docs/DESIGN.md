## 2026-11-11 · 在现有校样台补完任务

作者先判断某条模型评语是否适用，再核对改稿、把新版本交给自己的 AI。沿用纸面、深墨、红色定位与现有字号间距；评分原数仍在原位置，参考均分另起一行并标明声明来源。单篇声明与版本观察不静默合并。

原文处用原生 checkbox 切换上一保存版本的增删，新增带下划线、删除带删除线并有文字图例；使用 React 文本节点，保留中文、空白与原文，不执行引用中的 HTML。复制按钮紧邻版本正文，失败时打开完整只读文本供手动复制。校准备忘采用原生 details，默认收起，清楚标为草稿和待人工审阅；引用和备注只作为带引号的核查材料。

不增加动效或依赖；保留七项手机导航、短文稿正文间距和原有审阅→改稿→重新评测状态。[行为与证据](TASK-LOOPS-20261111.md)。

## 2026-11-01 · 校样台与自有任务

本轮在 `feat/product-depth-20261101` 开发，保留已有白纸、深墨、红色信号与Arial/Helvetica体系。对象是带着自己的故事、已有AI与评测结果来的作者/产品评审者。主操作是核对一条判断，界面不以总分和仪表盘代替它。

- 左侧170px窄量尺放五维、原分和人工状态，中间是可定位原文，右侧是当前评语、引用、评分锚点和复核。大屏三列在同一校样台中，平板量尺回到顶部，手机保留当前维度并切换原文/复核。
- 顶部红线标出自有文本入口，外部任务包按“原文→已有AI→返回复核”展开。资料库、现有JSON、高级历史工具承担次级任务，不让字段要求抢走原文的注意力。
- 复核判断直接显示为原生radio；处理动作只在存疑/待上下文时创建，完成checkbox只改人工任务，不改裁判分数。未解决事项作为报告的阅读起点。
- A/B对照以两份资料和比较条件为起点。分差只使用中性色、条件问题用轻红纸面提示，不把高分渲染成胜者。原文只标出首尾公共内容之间的变化区域，明确不是语义diff。
- 不引入新的装饰动效。状态变化使用160–180ms颜色/透明度反馈，维度切换的轻移保持原有逻辑；`prefers-reduced-motion`下关闭位移和过渡，操作不受影响。

完整行为与验收边界见[本轮记录](PRODUCT-DEPTH-20261101.md)。本节不声称已完成浏览器、真人可用性或模型效果实验。

## 使用任务与视觉方向

这是一张可工作的评审校样：先找低分与引句，再核对原文，最后记录自己的判断。不是用一个仪表盘总分替用户作发布决定。

采用用户指定的瑞士现代主义：Arial / Helvetica 字体体系、统一外边距、两列对照、清楚的字重与数字层级、中性底色与纸面、红色用于低分和定位入口。顶端的三条深线区分工作区域，不把每张评分卡封进重边框。

原文列在宽屏固定于视口内并可独立滚动，评分列按原规则从低分到高分排列。两列承担不同任务，不以相同高度填满空白。窄屏顺序阅读；头部保留全部五个导航项。

## 改动

- 保留五条主路由、可选接口设置、历史运行选择、版本对比、Bad Cases 与校验资料。
- 单篇页用五项水平量尺替代狭小雷达图。数值仍直接读取原始评分；比较页的雷达保留。
- 维度、裁判解释、引句、评分锚点形成明确阅读顺序；安全项单独展示。
- 引句定位后在原文中高亮。人工复核与模型原始记录分开，继续按样本/模型/运行隔离，可导出。
- 焦点可见、按钮按下反馈、导航状态过渡。切换实际样本/运行时，结果区用 220ms、5px 位移提示更新；引句高亮 550ms。没有循环背景或等待动画。
- `prefers-reduced-motion: reduce` 禁用上述动效；移动端保留来源、说明及全部操作。
