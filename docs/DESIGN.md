# Eval Lab 前端：瑞士现代主义

2026-10-27，先在独立分支完成本地评审，用户随后确认发布此版本。本轮不重跑模型成绩。

## 使用任务与视觉方向

这是一张可工作的评审校样：先找低分与引句，再核对原文，最后记录自己的判断。不是用一个仪表盘总分替用户作发布决定。

采用用户指定的瑞士现代主义：Arial / Helvetica 字体体系、统一外边距、两列对照、清楚的字重与数字层级、中性底色与纸面、红色用于低分和定位入口。顶端的三条深线区分工作区域，不把每张评分卡封进重边框。

原文列在宽屏固定于视口内并可独立滚动，评分列按原规则从低分到高分排列。两列承担不同任务，不以相同高度填满空白。窄屏顺序阅读；头部保留全部五个导航项。

## 改动

- 保留五条主路由、可选接口设置、历史运行选择、版本对比、Bad Cases 与校验资料。
- 单篇页用五项水平量尺替代狭小雷达图。数值仍直接读取原始评分；比较页的雷达保留。
- 维度、裁判解释、引句、评分锚点形成明确阅读顺序；安全项单独展示。
- 引句定位后在原文中高亮。人工复核与模型原始记录分开，继续按样本/模型/运行隔离，可导出。
- 焦点可见、按钮按下反馈、导航状态过渡。切换实际样本/运行时，结果区用 220ms、5px 位移提示更新；引句高亮 550ms。没有循环背景或等待动画。
- `prefers-reduced-motion: reduce` 禁用上述动效；移动端保留来源、说明及全部操作。
